# Guia de Entrega — GitHub e DIO

## GitHub

1. Crie ou abra o repositório destinado ao desafio.
2. Extraia o conteúdo do arquivo `ENTREGA_FINAL_DIO_PowerBI_Viviane_Rambor.zip`.
3. Envie **o conteúdo da pasta extraída**, mantendo a estrutura de diretórios.
4. Confirme que o `README.md` aparece na página inicial do repositório.
5. Abra a pasta `imagens` no GitHub e confirme que `modelo-star-schema.png` está visível.
6. Confirme que o arquivo `powerbi/Modelagem_DAX_PowerBI_Viviane_Rambor.pbix` foi enviado.
7. Copie a URL do repositório.

## DIO

No campo de entrega do desafio, cole a URL pública do repositório GitHub.

Descrição sugerida:

> Projeto de modelagem dimensional desenvolvido no Power BI com a base Financial Sample, incluindo transformações em Power Query, tabela fato, dimensões, DAX, dimensão calendário, Star Schema, arquivo PBIX e documentação do processo.

## Conferência antes de concluir

No Power BI Desktop, abra o PBIX, acesse a **Exibição de Modelo** e confira as seis tabelas. Caso apareça aviso de origem ao atualizar, altere o caminho para o arquivo `dados/Financial Sample.xlsx` deste repositório e aplique as alterações.
